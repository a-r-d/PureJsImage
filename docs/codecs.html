Codec details

JPEG

Practical

Decodes 8-bit baseline and progressive grayscale, YCbCr, RGB, CMYK, and YCCK. Handles 4:4:4, 4:2:2, 4:2:0, EXIF orientation, selected ICC profiles, and SDR primaries in gain-map files. Encodes baseline JPEG with quality and 4:2:0, 4:2:2, or 4:4:4 sampling.

Full JPEG checklist →

PNG

Practical

Decodes every legal grayscale, truecolor, indexed, and alpha combination at 1–16 bits, including Adam7, palettes, transparency, and color-profile handling. Encodes streaming 8-bit grayscale, RGB, or RGBA PNG with adaptive filters and compression levels 0–9.

Full PNG checklist →

WebP

Static

Decodes static VP8 lossy, VP8L lossless, extended alpha, and odd RIFF padding. Encodes first-party static lossy or lossless WebP. Animation is detected and rejected for pixel decode; full-frame VP8/VP8L working planes remain a documented memory target.

Full WebP checklist →

GIF

Decode only

Parses GIF87a/GIF89a, palettes, transparency, interlace, LZW data, frame rectangles, and disposal needed to produce the first composited frame. Metadata can count frames. Full animation decode/editing and GIF encoding are outside the current subset.

Full GIF checklist →

BMP

Practical

Decodes common Windows and OS/2 headers, indexed 1/4/8-bit pixels, RLE4/RLE8, RGB555/RGB565, top-down images, bitfields, and explicit alpha. Encodes 24-bit RGB and 32-bit RGBA BMP.

Full BMP checklist →

ICO

Decode only

Decodes multi-image Windows icons backed by embedded PNG or common 1/4/8/16/24/32-bit DIB pixels. Selection is deterministic; AND masks, partial alpha, and the legacy all-zero-alpha fallback are preserved. The selected image flows through normal crop, resize, PNG, JPEG, or WebP pipelines.

Full ICO checklist →

TIFF

Practical

Decodes Classic TIFF and BigTIFF strips or tiles across common grayscale, indexed, RGB, CMYK, YCbCr, and alpha layouts, including uncompressed, PackBits, Deflate, LZW, fax, and JPEG compression. Encodes uncompressed grayscale, RGB, or RGBA output.

Full TIFF checklist →

AVIF

Expanding

Metadata inspection covers a broad ISOBMFF/AVIF corpus. Pixel decode currently targets opaque 8-bit YUV 4:2:0 still images. Alpha, grids, high bit depth, complete in-loop filtering, and encoding remain unfinished and fail explicitly.

Full AVIF checklist →

HEIF / HEIC

Expanding

Decodes common opaque Main/Main Still Picture 8-bit and Main 10 YUV 4:2:0 intra stills, direct hvc1 items, and grid primaries. Supports crop metadata, orientation, nclx conversion, and PQ/HLG tone mapping. Auxiliary alpha, gain-map reconstruction, and multi-slice/tile coded pictures remain unsupported.

Full HEIF checklist →

Memory classes

The public API is common, but codec structure determines the working set. “Supported” does not automatically mean “bounded independently of source dimensions.”

PathCurrent working model
Baseline JPEGOne bounded MCU row; crop-aware RGB emission
Progressive JPEGCompact 16-bit coefficient planes, then bounded-row RGB reconstruction
PNGSequential scanlines and bounded output blocks; Adam7 retains compact requested samples
BMP / TIFFRow-, strip-, or tile-oriented paths for common layouts
ICOInspects the directory first, keeps embedded payloads as bounded views, and decodes only the selected image in rows
GIFFirst composited frame; source-sized indexed/canvas state may be required
WebPCurrent VP8/VP8L implementations retain source-sized working planes
AVIFCurrent decoder retains padded full-frame YUV and RGBA state
HEIF gridsTile selection helps crop workflows; full decode remains a measured optimization target

Choose an output

  • JPEG: photographs and broad compatibility. Alpha is flattened to white by default or to a requested background.
  • PNG: exact alpha, screenshots, graphics, or lossless round trips.
  • WebP: static web delivery with lossy or exact lossless modes; benchmark the current full-frame memory behavior for large inputs.
  • BMP: simple interchange with legacy systems that require RGB/RGBA bitmap output.
  • TIFF: uncompressed grayscale/RGB/RGBA output for compatible document and imaging workflows.
Metadata round trips are not promised. The codecs expose selected metadata for inspection and color conversion, but broad EXIF/XMP/IPTC/ICC preservation on re-encode is not implemented.

Planned formats

CUR, JPEG 2000, and JPEG XL are not current codec entry points. The roadmap favors a coherent, tested common subset over premature format-name coverage.

Designed from the bytes up

Less image machinery.
More room for your app.

PureJsImage keeps the package graph small and the working set bounded. It does the useful work without silently outsourcing the hard parts.

Bounded by design

JPEG MCU rows, PNG scanlines, TIFF strips, and HEIF tiles avoid a source-sized RGBA bitmap wherever the format permits it.

Hostile-input ready

Dimensions, allocation budgets, box extents, entropy reads, and truncation are checked. Unsupported input fails with typed errors.

Only the codecs you choose

The core imports no codec. Register JPEG and PNG—or all nine—once, then reuse the immutable library across warm invocations.

First-party codec stack

One pipeline. Real format depth.

The default reference engine decodes common web and camera images, transforms in bounded blocks, and encodes practical output formats without native addons, WASM, or external binaries. Future per-codec WASM accelerators remain explicit opt-ins.

A small, explicit API

From upload to web-ready in one readable pipeline.

Open lazily, inspect without decoding pixels, compose immutable operations, and choose a sink only when you are ready to execute.

  • Node paths and Buffers, browser Files and Blobs, typed arrays, or custom range sources
  • Ordered crop, resize, rotate, flip, flop, format conversion, and quality controls
  • Metadata stripped by default, with explicit EXIF and ICC preservation
  • Buffer, Uint8Array, Blob, custom sink, or failure-safe direct file output

normalize-upload.ts
import { createImageLibrary } from 'purejsimage'
import { jpegCodec } from 'purejsimage/codecs/jpeg'
import { pngCodec } from 'purejsimage/codecs/png'

// Create once, then reuse across requests.
const images = createImageLibrary([
  jpegCodec,
  pngCodec,
])

const image = await images.open('input.jpg')

await image
  .autoOrient()
  .resize({
    width: 1200,
    withoutEnlargement: true,
    kernel: 'lanczos3',
  })
  .jpeg({ quality: 80 })
  .toFile('output.jpg')

## Fixture boundaries

- **nanonis-afm** (representative): Nanonis SXM maps exposed as labeled planes. Provenance: Pinned FAIRmat-NFDI pynxtools-spm Generic 4 AFM fixture. Oracle: First dataset exposes calibrated x/y axes and a readable bounded plane.
- **igor-wave** (representative): Igor binary waves of supported rank and numeric sample types. Provenance: Pinned AFMReader Asylum Research Igor binary wave fixture. Oracle: First dataset exposes at least two axes and a readable plane.
- **x3p-surface** (representative): X3P ZIP surface with main.xml and binary data member. Provenance: Pinned OpenFMC ISO 5436 sample archive. Oracle: First dataset exposes a 4x4 calibrated plane.
- **envi-hyperspectral** (representative): ENVI header/data companion pair with bounded band selection. Provenance: Repository-generated ENVI hyperspectral demo header and binary pair. Oracle: Header and binary resolve as one dataset with a readable band plane.
- **fits-cube** (representative): FITS image HDU numeric cube. Provenance: Repository-generated FITS cube used by the scientific demo. Oracle: Primary image dataset exposes x/y axes and a readable plane.
- **mrc-volume** (correctness-only): MRC mode-1 little-endian 2D volume with MAP signature. Provenance: Deterministic first-party MRC benchmark fixture. Oracle: 2x2 int16 plane values are finite and metadata includes cell dimensions.
- **ordinary-tiff** (representative): Ordinary TIFF image directory and bounded region reads. Provenance: Pinned LibTIFF RGB sample. Oracle: First TIFF dataset exposes x/y axes and a readable region.
- **ome-tiff** (correctness-only): OME-TIFF single-plane XYZCT image with embedded XML. Provenance: Deterministic first-party OME-XML TIFF benchmark fixture. Oracle: OME metadata selects the OME reader and exposes x/y/z/channel/time axes.
- **aperio-svs** (representative): Aperio SVS tiled pyramid with direct tile/range reads. Provenance: Pinned Aperio CMU-1 small-region whole-slide fixture. Oracle: Pyramid dataset exposes a bounded readable region without full-source materialization.
- **digital-micrograph-2d** (representative): DM3/DM4 numeric 2D image datasets. Provenance: Pinned RosettaSciIO DigitalMicrograph 2D test fixture; generated fallback is deterministic. Oracle: First supported image dataset exposes a readable 2D plane.
- **digital-micrograph-4d-stem** (correctness-only): Explicit diffraction-image/Data-Order-Swapped 4D STEM semantics. Provenance: Deterministic first-party DigitalMicrograph 4D-STEM fixture. Oracle: When the fixture is 4D STEM, kx/ky is readable with fixed scan axes.
- **tia-ser-image** (representative): TIA SER image elements exposed as calibrated planes. Provenance: Pinned RosettaSciIO TIA SER image fixture; generated fallback is deterministic. Oracle: Image dataset exposes x/y with one fixed element index.
- **tia-ser-spectrum** (representative): TIA SER spectrum image with energy series reads. Provenance: Pinned RosettaSciIO TIA SER spectrum-image fixture; generated fallback is deterministic. Oracle: Spectra dataset exposes x/y/energy and a bounded energy series.
- **tia-emi** (representative): EMI metadata with numbered SER companion resolution. Provenance: Pinned RosettaSciIO TIA EMI/SER companion set; generated fallback is deterministic. Oracle: At least one ser-* dataset opens and retains EMI metadata/calibration evidence.
- **ncem-emd** (representative): NCEM EMD HDF5 image/spectrum datasets with bounded contiguous reads. Provenance: Pinned RosettaSciIO NCEM EMD image fixture; generated fallback is deterministic. Oracle: First image dataset exposes a readable plane or series according to rank.
- **velox-emd** (representative): Velox EMD image hierarchy with HDF5 metadata columns. Provenance: Pinned RosettaSciIO Velox EMD image fixture; generated fallback is deterministic. Oracle: First image dataset exposes a readable plane.
- **velox-emd-complex** (representative): Velox EMD complex two-component image samples. Provenance: Pinned RosettaSciIO Velox complex FFT fixture; generated fallback is deterministic. Oracle: Complex dataset preserves two output components and a readable plane.
- **rpl-raw** (representative): RPL vector-record header with RAW companion and calibrated depth axis. Provenance: Pinned RosettaSciIO RPL/RAW interchange pair; generated fallback is deterministic. Oracle: Depth-fixed x/y plane is readable and the companion is resolved.
- **meta-image-mha** (correctness-only): MHA LOCAL payload with 2D uchar data. Provenance: Deterministic first-party MetaImage local-payload fixture. Oracle: 2x2 local MetaImage plane is readable.
- **meta-image-mhd** (correctness-only): MHD header with an external RAW companion. Provenance: Deterministic first-party MetaImage detached-payload fixture. Oracle: Detached 2x1 uint16 plane resolves the RAW companion and is readable.
- **npy-c-order** (correctness-only): NPY v1 little-endian uint16 C-order array. Provenance: Deterministic first-party C-order NPY benchmark fixture. Oracle: C-order axes are preserved and a plane is readable.
- **npy-fortran-order** (correctness-only): NPY v1 little-endian uint16 Fortran-order array. Provenance: Deterministic first-party Fortran-order NPY benchmark fixture. Oracle: Fortran-order axes are preserved and a plane is readable.
- **blockfile** (representative): BLO navigation plus bounded diffraction frame reads. Provenance: Pinned RosettaSciIO Merlin blockfile fixture; generated fallback is deterministic. Oracle: A fixed navigation position exposes a readable diffraction plane.
- **mib** (correctness-only): MIB header with a small uint8 diffraction frame. Provenance: Deterministic first-party Merlin MIB benchmark fixture. Oracle: MIB frame dataset exposes a readable diffraction plane.

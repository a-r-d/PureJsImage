# PNG Rust/WASM decode and encode benchmark — 2026-08-09

## Result

The optional bounded-row PNG accelerator provides a clear complete-workload benefit on representative
large images while retaining native zlib and exact output.

On the 1920x1080 matrix, warm SIMD decode was 28.4%-46.9% faster than the TypeScript reference. Warm
SIMD encode was 39.0%-52.2% faster for high-entropy RGB/RGBA input. Smooth-image encode improved by
10.8%-22.2%; native deflate dominates those highly compressible cases, so this result does not claim a
large encode gain for every PNG content class.

The representative high-entropy RGBA workload crossed the plan's complete-workload gate in both
directions: decode improved 32.1% and encode improved 39.0%. The result includes PNG parsing, native
inflate/deflate, JavaScript/WASM copies, bounded block processing, chunk CRC, and sink assembly as
applicable. No custom DEFLATE implementation was justified by this iteration.

## Correctness gate

All timing cells passed before the report was written:

- every decoded pixel SHA-256 matched its generated raw fixture;
- scalar and SIMD encoded PNG SHA-256 and byte count matched the TypeScript reference exactly;
- RGB8 and RGBA8, smooth and seeded high-entropy content, and 256x256 and 1920x1080 dimensions were
  included;
- the focused compatibility suite separately covers gray8 and PNG filters 0-4.

Machine-readable evidence: `benchmark/results/png-wasm-2026-08-09.json`.

## Cold observations

Each cold cell used three isolated processes and reports the median. Large-image SIMD cold gains were:

- decode: 19.1%-33.1%;
- encode: 18.6%-48.5%.

Median WASM read/compile/instantiate/ABI validation was 0.34-0.66 ms in the large warm workers. The
small 256x256 matrix remains in the JSON so selector thresholds can be revisited without treating a
large-image result as evidence for every image size.

## Size and memory

| Artifact | Raw | gzip | Brotli |
| --- | ---: | ---: | ---: |
| Scalar | 3,884 B | 1,664 B | 1,451 B |
| SIMD | 7,293 B | 3,025 B | 2,577 B |

The 1920x1080 SIMD linear-memory high-water mark was 1,507,328 bytes for RGB8 and 1,638,400 bytes for
RGBA8. The accelerator retains only bounded input, output, and previous-row regions; it does not stage
a full inflated image or source-sized pixel frame. Absolute process maximum RSS ranged from 9.5 MiB
below to 10.0 MiB above the corresponding
TypeScript worker depending on content and direction; detailed baselines, deltas, external memory, and
ArrayBuffer values are retained in the JSON rather than reduced to a single noisy percentage.

## Reproduction

```sh
npm run bench:png:wasm -- --output benchmark/results/png-wasm-2026-08-09.json
```

Environment: Node.js 24.16.0, V8 13.6.233.17-node.49, zlib 1.3.1-e00f703, Linux
6.17.0-41-generic x64, Intel Core i7-10700. Cold cells use three isolated processes. Warm cells use one
isolated process, two warmups, and five measured runs. Fixture generation seed: 1511508451.

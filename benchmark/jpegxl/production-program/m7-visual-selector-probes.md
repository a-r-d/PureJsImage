# M7 visual selector probes after the frozen qualification

The public encoder remains at implementation `55c1d74b2ced4f5bd85afb57580be04a427c4c15`. These probes tested whether the existing DCT8/Hornuss/rectangular selector's requirement for both lower estimated bits and no increase in any channel's squared error caused the remaining visual defects. No candidate was retained, and the [final qualification](m7-visual-defects-final.md) is unchanged.

The fixed eight-image development diagnostic contains four text/map crops and four photographic derivatives, at effort 7 and distances 1, 2, and 3. It is capped at a 1024-pixel edge. Each of the 24 streams in the [baseline](visual-selector-probes/baseline.json) and five candidate reports encoded successfully and decoded in pinned native libjxl, Rust, and the repository decoder within one RGB8 sample. The six [bounded receipts](visual-selector-probes/) show a 3 GiB process-tree limit, zero swap, and peaks from 572.7 to 605.8 MiB. This diagnostic is not the approved 2 MP matrix or an original-size visual review. The previously observed split was not used in these trials.

The trial cost was `D + lambda * R`, with `D = 2 * Y squared error + X squared error + B squared error`, `R` the existing coefficient bit estimate plus two alternate-strategy signaling bits, and `lambda = factor * DCT8 distortion / max(8, DCT8 estimated bits)`. The same-region DCT8 estimate was the baseline. The factor and an optional per-block rate guard were the only changes between candidates. The bit estimate omits actual context and entropy-model costs, so its predictions require encoded-byte validation. These trials did not add DCT16, alter quantization, or change public distance bounds.

The text/map diagnostic often improved. In the last trial, the distance-3 table crop shrank 7.79% with +1.756 SSIMULACRA2 and -0.305 Butteraugli; the map crop shrank 3.46% with +0.774 and -0.483. But the natural-texture crop grew 5.23% with +0.214 Butteraugli, and the sunset crop grew 2.42% while losing 0.049 SSIMULACRA2. Requiring *estimated* bit savings did not prevent those actual byte regressions. Equal-distance scores alone do not prove a matched-quality size gain or a visible 1:1 defect correction. No original-size, HDR, alpha, or browser qualification was run for rejected candidates.

The next selector experiment needs a calibrated estimate of actual token, context, and transform-map cost, plus native-size reconstructions around the four open defect crops. The first revised selector must pass the neighboring photos and texture before complete originals or another approved matrix run. The baseline source SHA-256 is `61cf57685f075788b2d4d7316e5b40e44e01353edc817ef71366398702632e9a`; each raw report records its candidate source, input, tool, stream, and decoded hashes. Reproduce one candidate with `node benchmark/jpegxl/run-m7-bounded.ts unique-id node benchmark/jpegxl/run-m7-diagnostic.ts own unique-id` after applying its described selector trial.

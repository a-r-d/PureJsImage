Disabling its patch generator expands those streams from 243,762 to 670,599 bytes and from 149,228 to 736,428 bytes. The new first-party writer finds byte-identical small components, packs one copy of each into a Modular reference atlas, clears those rectangles in a step-4 quantized display frame, and restores them with JPEG XL patch features. It accepts this two-frame candidate only when it saves at least 5% against the already selected stream. The selector is restricted to opaque sRGB RGB8, at least 8 MP, effort 7, distance at least 2, nonprogressive output, and a pale-page sample. Lossless, alpha, HDR, other efforts and smaller images retain their encoder paths. The native implementation was used to identify the method and measure the gap; production code is first-party TypeScript.

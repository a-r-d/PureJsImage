### Short description

PureJsImage is a strict TypeScript library for image codecs and low-memory raster processing in Node.js and modern browsers.

### Scientific description

PureJsImage is a free, open-source TypeScript library for decoding, inspecting, processing, and converting ordinary images and scientific rasters in Node.js and modern browsers. It provides explicit readers for microscopy, whole-slide pathology, medical imaging, electron microscopy, spectroscopy, hyperspectral, and multidimensional array formats. These include OME-TIFF, OME-Zarr, Aperio SVS, DICOM, NIfTI, MRC/CCP4, NRRD, DigitalMicrograph, EMD, ENVI, and FITS. Range-backed readers can request selected regions, tiles, volume planes, and metadata while preserving native numeric samples where supported. The default package has no runtime dependencies. Optional JPEG and PNG WebAssembly accelerators require explicit registration.

### BIII description

PureJsImage is a TypeScript image-processing and format-I/O library for Node.js and modern browsers. It reads ordinary images and scientific raster formats used in microscopy, whole-slide pathology, medical imaging, and electron microscopy. Supported reader families include OME-TIFF, OME-Zarr, Aperio SVS, DICOM, NIfTI, MRC/CCP4, NRRD, DigitalMicrograph, EMD, and other instrument formats.

Its scientific API preserves native numeric samples and labeled axes. Range-backed readers can fetch selected regions, tiles, volume planes, and metadata where the source format permits it. The package also provides image transforms, format conversion, and browser examples for scientific image viewing. Support boundaries are documented per format.
